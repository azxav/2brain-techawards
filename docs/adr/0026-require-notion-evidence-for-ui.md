# Require Notion evidence for every UI decision

The 2Brain Workspace is a source-backed translation of Notion rather than a loosely inspired redesign. Every layout, component, interaction, typography, color, spacing, state, motion, and responsive choice must cite a supplied or measured Notion reference in a design-evidence matrix before implementation; when 2Brain has a domain feature with no exact Notion equivalent, the closest Notion pattern must be named and the mapping documented, and the discarded admin design is never used as a fallback.

Accepted evidence sources are the user's supplied screenshots, current official public Notion product and help material, and publicly accessible Notion interface captures. Private Notion workspace access is excluded; when a necessary pattern lacks reliable public evidence, work pauses for one targeted screenshot from the user.
