# Onboard the first Administrator through the trust loop

An empty 2Brain Workspace presents its first Administrator with a Notion-grounded Setup Checklist: add an HTTPS Git Source, complete the first synchronization, inspect a compiled Page and its provenance, invite Members and grant Source Access, and register the first Agent with least-privilege access. The checklist leaves Home after completion but remains available in Settings. Members see Workspace is being set up only while the Workspace has no synchronized Knowledge; once Knowledge exists, a Member with No Source Access sees a distinct access-required state without Administrator controls or fabricated content.

ADR-0049 clarifies the two evidence classes in this flow. The Administrator checklist's connect-and-synchronize steps remain Managed Git-specific. Member empty/access states evaluate all active catalog Pages: a durable built-in or unmanaged Page is Knowledge and must not be hidden or described as an empty Workspace.
