# Make responsiveness measurable at the v1 scale target

At the agreed organization scale, the authenticated shell is usable within 2.5 seconds at p75; cached navigation responds within 200 milliseconds; list, filter, and deterministic Search results return within 1 second at p95; live operational changes appear within 5 seconds; and Ask 2Brain acknowledges within 1 second and begins progress or streamed content within 3 seconds. Synthesis has no fixed completion deadline, but cancellation must always remain available.
