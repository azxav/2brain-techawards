# Replace the admin frontend while preserving backend capabilities

The existing admin website's frontend, visual system, navigation, and components will be discarded and replaced with a Notion-grounded 2Brain Workspace. Existing backend code capabilities and compatibility routes for authentication, authorization, request logging, Agent management, jobs, and health remain and will be exposed through role-gated Settings. Clean Start imports none of their stored records, and new human authentication replaces the bootstrap-only browser session as the normal Member boundary.
