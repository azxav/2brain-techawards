# Use two Workspace roles and separate Source access

2Brain v1 has two human roles, Member and Administrator, while Source Access remains an orthogonal permission dimension. Administrator oversight of complete structured Agent Activity is the explicit exception and does not grant ordinary Knowledge browsing outside the Administrator's Source Access. Additional roles such as Editor, Analyst, or Source Manager were rejected because v1 has no rich editor and coupling content access to role names would create unclear authority and unnecessary permission combinations.
